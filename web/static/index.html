      初始化

      登录后需要先拉取选课参数。切换选课轮次或页签后，可点击「重新初始化」刷新。

      选课页签

      初始化后显示可用的选课页签。

      课程列表

      打开本页会自动加载已缓存的课程；缓存为空时点击「获取课程列表」从学校拉取。未加载详情的教学班可点击「详情」展开教师 / 时间 / 容量。

      已选课程查询

      输入学年学期后查询已选课程。

      考试成绩查询

      输入学年学期后查询考试成绩。

      愿望清单

      每行一项，空行和首尾空格会被忽略。课程名任意一项命中即可；只填教师时教师命中即可； 填了课程类型时，类型命中后教师还要命中（教师留空即不限）。清单会随账号保存，登录、初始化、重启 WebUI 后都还在；也作为自动选课的默认条件。

      自动选课

      按愿望清单反复尝试，并周期性重新查询课程列表（已选人数、新放出来的名额、新开的教学班），直到选上、取消、轮次用尽或到达运行上限。进度与结果会显示在右侧任务面板。

      0 = 不限
      小时

      自动选课是超长任务：默认最长跑 24 小时，也可以指定小时数或结束时间；蹲名额不用一直盯着页面。

      随账号保存；还需在「服务端配置 → 邮件通知」启用 SMTP 并勾选「自动选课结果通知」。

      个人信息

      从学校教务系统读取当前账号的学籍信息。查询要求已登录，不会在后台静默重登。

      点击「获取个人信息」后显示姓名、学号、学院、专业等字段。

      大头照

      读取教务系统里的学生证件照原图；学校未上传照片时会给出提示。

      识别配置

      可填绝对路径；留空时依次在程序目录、当前目录及其 models/ 下查找。
      6 个字符概率的乘积；低于阈值就转人工输入。默认 0.9。
      0 = 按 CPU 核数自动决定。

      替换模型

      上传 .onnx 文件（不超过 64 MB），会保存到配置文件旁的 models/ 并自动启用。

      测试识别

      选一张验证码图片，用当前模型识别一次；只在本机推理，不会提交到学校。

      模型文件不随仓库分发（约 11 MB）。保存或上传后对所有账号立即生效，无需重启。

      SMTP 邮件通知

      自动选课结束时（需勾选「自动选课结果通知」，且该账号没有关闭「完成后发送邮件通知」），把结果发到指定邮箱。 配置保存在服务端 server.json，所有账号共用；密码不会回显，留空表示不修改。

      只填主机名；465 端口按 SSL 直连，其他端口自动尝试 STARTTLS。
      QQ / 163 邮箱一般用 587（STARTTLS）或 465（SSL）。
      多数邮箱与发件人相同；留空时自动使用发件人邮箱。
      密码只保存在服务端，不会返回给浏览器。
      每行一个，也支持逗号 / 分号分隔；重复地址会自动去重。
